# Commute lab report

The viewer can compare the full drives or the homebound log trimmed at the grocery stop. It currently plots five derived signals. The captures also preserve standard OBD replies for fuel rate, pedal position, load, airflow, and operating temperatures. Those channels can be decoded after recording.

The return trip illustrates two useful comparison axes. The candidate CVT fluid temperature reached 70°C sooner in elapsed engine time and farther into the trip. The work and culled home captures cover about 29.2 km each, which makes distance and cumulative fuel natural comparison views.

Speed arrives about once per second. Many supplemental signals arrive every three seconds. Use actual timestamps, pair samples within stated tolerances, and leave outages visible. Pulley scale, shifter interpretation, and absolute engine power still need reference measurements.
