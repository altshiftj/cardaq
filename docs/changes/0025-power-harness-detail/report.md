# Vehicle power harness detail

The vehicle power overview identifies both converters. The existing hub branch sheet starts at the HK4 output. Neither sheet identifies the individual Mini-Box contacts or traces the factory vehicle leads on both supplies. A bench assembly needs those connections and a clear boundary at each unselected USB-C interface.

Figure 1.0 identifies the Mini-Box input and output by contact number in a board-layout view. The HK4 guide identifies its three input leads, captive output and combined load limit. The standard hub schematic connects PWR1 to carrier VIN and ground. Civic fuse slots, upstream fuse ratings, ground points, mating hardware and the Pi shutdown interface still require identification.
