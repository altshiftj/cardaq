# Confidence across recording variations

The Python suite checks worked examples of decoding, recorder recovery, sparse series and longitudinal scoring. Review probes showed that it can also pass with missing dashboard JavaScript, missing cylinder polling and incorrect health aggregation. Several fixtures fix the sample cadence or use constant readings, so they leave equivalent inputs and decision boundaries untested.

The next tests should compare deliberately varied inputs with independent expected results and follow representative data across the serial, CSV and report boundaries. Browser assertions should cover visible behavior of an exported file. All scenarios can use synthetic inputs.
