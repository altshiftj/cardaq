# Record a drive with one command

Read the VIN locally, validate complete addressed frames, and derive a repeatable vehicle ID. Give supported models a readable label and choose the matching polling profile. Use the standard profile for other cars and mark missing identity explicitly.

Carry the identity into the managed filename, sidecar and CSV. Keep explicit output paths and exclusive file creation. Recheck identity when reconnecting before accepting further data. Exercise startup, conflicting VINs, repeated trips, reconnects and the existing recorder with offline fixtures.
