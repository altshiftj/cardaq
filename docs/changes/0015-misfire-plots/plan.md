# Plot observed changes by cylinder

Decode the saved replies using the health report's decoder. Keep each cylinder's valid observations on the recording's elapsed clock. Use the first as a baseline, draw a marker for each positive change, and accumulate those increases for the second plot. A decrease establishes a new baseline. Keep its history visible.

Use the same cylinder colors and elapsed-time scale in both plots. Offer one of the selected drives at a time. Check batched increases, carried counts, decreases, empty cylinders and missing replies against fixtures and the saved commutes, then regenerate the offline viewers.
