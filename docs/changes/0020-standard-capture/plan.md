# Discover the connected vehicle before recording

Add an opt-in standard CAN profile alongside the default Civic profile. Start adapter protocol discovery, inventory support bitmaps on the live connection, and poll the advertised Mode 01 data PIDs. Record the inventory and original frame identifiers. Announce readiness after an addressed data reply. Repeat discovery on reconnect.

Decode common engine data for the conventional 11-bit engine response ID and the existing 29-bit engine response ID. Keep other responders' frames available for later identification. Test the serial sequence, saved CSV and viewer offline. In the parked RAV4, identify the adapter, sample the inventory, and verify a short recording before the first trip. Toyota-specific transmission measurements depend on separate evidence.
