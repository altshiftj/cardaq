# Longitudinal powertrain monitoring

The commute dashboard explains individual drives. A long-term report needs one comparable observation per trip, with the operating conditions and sample coverage kept alongside it. The two available commutes differ in route direction, starting temperature and reported selector use. A full return capture and its culled copy also contain the same journey.

The saved replies contain fuel-system state, fuel trims, temperatures, shaft-speed candidates and per-cylinder onboard monitor results. These support an initial history without a new vehicle query. Actual selector position, converter-clutch command, transmission pressure, and service history still require independent evidence.
