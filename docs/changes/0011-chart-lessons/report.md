# Chart lessons

The explorer pairs a short definition with an interpretation and optional recording-specific observations. The temperature comparison exposed an unanswered question. A reader needs to know which part of the vehicle a temperature represents before interpreting a warm start. Likewise, understanding a speed ratio requires knowing which shaft supplies the numerator.

The catalog includes module-reported values, provisional Honda fields and recorder-side calculations. The reporting module alone cannot establish where a sensor is mounted. The health report adds another layer by reducing qualifying samples to a single value for each trip.
