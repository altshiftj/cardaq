# Trip notebook plan

1. Detect recorded engine starts, stops, launches, sustained cruise, probable fuel cut, and telemetry gaps on elapsed capture time.
2. Calculate observed temperature milestones relative to engine start. Match their distances to the gap-aware distance series.
3. Measure dwell in consistent road-speed bands. Apportion each observed moving interval across the speed bands it crossed.
4. Show notebook comparisons in the offline viewer and open chart windows around selected events.
5. Validate cutoff, gap handling, and browser interactions on the culled and full captures.
