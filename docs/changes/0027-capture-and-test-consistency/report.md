# Capture and test consistency

The installed-wheel CI job uses unittest discovery. The local editor selects pytest. Both runners execute the existing 105 ordinary test cases, but unittest discovery skips standalone pytest functions. Five Chromium tests run separately.

A replayed ECU rejection of an RPM request increments the Civic recorder’s reply count and contributes to the viewer’s successful-request latency. The standard recorder classifies the same response as adapter status. The Honda measurement and monitor decoders also repeat the shared CAN frame reader’s handling of the adapter’s optional length digit.

Health histories are organized by the vehicle name in the manifest. The CSV reader already extracts a vehicle hash when available. A manifest can currently combine captures from two identified vehicles and use both for the same baseline. Older recordings can legitimately lack this identifier.
