Cylinder misfire monitors

Each cylinder takes a turn giving the engine a push. When the computer detects a missing or weak push, it can add one to that cylinder’s misfire count. Read the arrows left to right. Going from 2 to 3 means the computer counted one more.

Why a count can start above zero

The recorder asks the car for its count every so often. The peak time is when the recorder first saw the highest count. The engine could have missed a beat any time since the previous check. A 3 → 0 at startup can be the previous trip’s count clearing. The weighted reading summarizes several driving cycles.
